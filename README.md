# Портфолио — Анна Павлова

Двухстраничный сайт-портфолио, опубликован на Vercel.

## Страницы

| файл | что на странице |
|---|---|
| `index.html` | «обо мне»: титул, обо мне, навыки, образование, анонс кейсов, контакты |
| `works.html` | «кейсы»: пять работ с фильтром по направлениям, контакты, подвал «о сайте» |

Между страницами — переключатель «обо мне / кейсы» вверху экрана.

## Структура

```
├── index.html     — страница «обо мне»
├── works.html     — страница «кейсы»
├── styles.css     — общие стили обеих страниц, mobile first
├── script.js      — общий JavaScript обеих страниц
└── images/
    ├── anna.webp  — фото на титуле
    └── covers/    — обложки кейсов, все 4:3
```

## Адаптивность

| экран | раскладка |
|---|---|
| до 600px | одна колонка, поля 16px |
| от 600px | листы до 760px по центру, навыки и карточки в две колонки |
| от 960px в ландшафте (ПК) | горизонтальная лента листов; ширина карточек кейсов зависит от высоты экрана, поэтому лист влезает по высоте |

## JavaScript

- горизонтальная лента: колесо мыши, перетаскивание, стрелки на клавиатуре;
- шкала прогресса с засечками и счётчиком листов;
- фильтр кейсов по направлениям;
- копирование почты в буфер обмена;
- смена раскладки под экран через `matchMedia`.

## Использование AI

Claude (Claude Opus 5.5, Anthropic) в Claude Code разделил одностраничный сайт на две страницы: разнёс разделы, добавил переключатель страниц и лист-анонс кейсов, проверил обе страницы в браузере на ширинах телефона и ПК.
